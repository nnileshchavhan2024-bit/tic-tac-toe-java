# Tic-Tac-Toe Game (Java Swing)

A two-player Tic-Tac-Toe game with a graphical interface, built in Java using Swing.

## Features
- 3x3 game board with clickable buttons
- Two players (X and O) with different colours
- Winner detection with highlighted winning line
- Restart option after each game

## Tech Used
- Java
- Swing (JFrame, JButton, JOptionPane)
- Event handling (ActionListener)

## How to Run
1. Download or clone this repository
2. Open the project in IntelliJ IDEA (or any Java IDE)
3. Run the main class
4. Click on the boxes to play
